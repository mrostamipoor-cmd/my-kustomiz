Sample Kustomize+Helm app generated by generate-pwn-app.sh

Tree:
  ./my-kustomize/
  ├── kustomization.yaml
  └── charts/pwn/
      ├── Chart.yaml
      ├── values.yaml
      └── templates/
          ├── deployment.yaml
          └── service.yaml

Render locally:
  kustomize build --enable-helm ./my-kustomize

Pack as OCI (optional):
  tar -C ./my-kustomize -czf /tmp/pwn-kustomize.tgz .
  # then oras/crane push to
  # oci://docker-releases-local.artifactory.twitter.biz/psec/my-kustomize:0.1.0
